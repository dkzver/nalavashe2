Создай полноценную 3D браузерную игру LAVA DASH

Ты — профессиональная команда разработчиков браузерных 3D-игр: Game Designer, 3D Artist, JavaScript Developer и UI/UX Designer.

Создай законченную, запускаемую браузерную игру для сайта ресторана «На LAVAше» — https://nalavashe-vl.ru/.

Название игры: LAVA DASH.

Главная задача — привлечь посетителей на сайт ресторана, развлечь их и мотивировать сделать заказ.

1. Технологии

Three.js — основная 3D-графика.

WebGL — рендеринг.

JavaScript ES Modules.

HTML5 и CSS3 — интерфейс.

Vite — запуск и сборка проекта.

LocalStorage — сохранение рекорда.

Без Phaser и без 2D-замены вместо 3D.

Игра должна запускаться командой npm run dev и собираться командой npm run build.

2. Главный персонаж

Создай оригинального мультяшного героя — живую шаурму с глазами, руками и ногами.

Внешность:

золотистый лаваш;

аппетитная начинка;

большие выразительные глаза;

мультяшная улыбка;

короткие руки и ноги;

забавная анимация бега;

плавная анимация прыжка и подката.

Персонаж должен быть полноценной 3D-моделью из геометрии Three.js, а не плоской картинкой.

Предусмотри возможность впоследствии заменить временную модель на GLB/GLTF-модель настоящего маскота ресторана.

3. Игровой мир

Создай красочную трёхмерную городскую улицу в мультяшном стиле.

Игрок бежит по дороге, камера находится сзади персонажа и немного выше.

В окружении:

здания;

вывески;

фонари;

деревья;

дорожные знаки;

декоративные элементы;

фирменные элементы ресторана.

Дорога имеет три полосы движения.

Мир должен бесконечно генерироваться впереди игрока, а старые объекты удаляться позади него.

4. Управление

Компьютер:

A / ← — влево;

D / → — вправо;

W / ↑ / Space — прыжок;

S / ↓ — подкат.

Телефон:

сенсорные кнопки;

свайпы влево и вправо;

свайп вверх — прыжок;

свайп вниз — подкат.

Управление должно быть отзывчивым, без задержек.

5. Препятствия

Реализуй:

дорожные конусы;

дорожные барьеры;

автомобили;

мусорные контейнеры;

другие подходящие городские препятствия.

Игрок должен уметь перепрыгивать и обходить препятствия.

При столкновении игра заканчивается.

6. Собираемые предметы

На дороге появляются:

шаурма;

бургеры;

картофель фри;

напитки;

специальные бонусы.

Каждый предмет должен иметь собственную 3D-модель, анимацию вращения и эффект сбора.

Начисление очков:

шаурма: +100;

бургер: +150;

напиток: +50;

специальный бонус: +500.

7. Игровая механика

Бесконечный раннер.

Скорость постепенно увеличивается.

Сложность растёт с пройденной дистанцией.

Счёт отображается в реальном времени.

Отображается дистанция.

Отображается количество собранных предметов.

Лучший результат сохраняется в браузере.

Одна игровая сессия рассчитана примерно на 2–3 минуты.

Добавь небольшие визуальные эффекты при сборе бонусов и столкновениях.

Игра должна быть честной: столкновения, сбор предметов и начисление очков определяются игровой логикой, а не случайными визуальными эффектами.

8. Интерфейс

Создай качественный игровой интерфейс.

Главное меню:

логотип LAVA DASH;

кнопка «ИГРАТЬ»;

кнопка «КАК ИГРАТЬ»;

лучший результат;

красивый фон с персонажем.

Игровой экран:

счёт;

дистанция;

собранные предметы;

пауза;

мобильное управление.

Экран окончания игры:

результат;

дистанция;

количество собранных продуктов;

лучший результат;

кнопка «ЕЩЁ РАЗ»;

кнопка «НА САЙТ РЕСТОРАНА».

9. Маркетинговая интеграция

Игра создаётся для ресторана «На LAVAше».

Добавь:

фирменную цветовую гамму;

логотип или место для логотипа;

ссылку на https://nalavashe-vl.ru/;

кнопку перехода к заказу;

рекламный экран после завершения игры.

Не придумывай реальные скидки и промокоды. Предусмотри возможность подключить проверяемые сервером промокоды в будущем.

10. Звук

Добавь:

фоновую музыку;

звук прыжка;

звук сбора еды;

звук столкновения;

звук нажатия кнопок.

Предусмотри включение и выключение звука.

11. Качество и производительность

Адаптация для компьютеров, планшетов и смартфонов.

Оптимизация количества полигонов.

Ограничение количества одновременно отображаемых объектов.

Корректное освобождение ресурсов Three.js.

Обработка изменения размера окна.

Корректная работа на современных мобильных браузерах.

Экран загрузки.

Отсутствие ошибок в консоли.

Корректная работа при повторном запуске.

12. Структура проекта

Раздели проект на модули:

src/main.js

src/game/Game.js

src/game/Player.js

src/game/World.js

src/game/Obstacles.js

src/game/Collectibles.js

src/game/Collision.js

src/game/Controls.js

src/game/UI.js

src/game/Audio.js

src/style.css

public/assets/

Не размещай всю игру в одном огромном файле.

Не ограничивайся демонстрацией или макетом интерфейса.

Создай реально работающую игру, которую можно пройти.

Создай все файлы проекта.

Установи необходимые зависимости.

Запусти игру.

Проверь мобильный интерфейс.
